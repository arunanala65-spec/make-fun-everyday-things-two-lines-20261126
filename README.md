A TypeScript program that explains a toaster to a 10-year-old in exactly two lines: a toaster is a tiny sunbed for bread, each slice lying flat under glowing wires until it pops up golden and crisp — and the second line honestly says what the sunbed picture maps (the lying flat, the heat, the golden finish) and what it leaves out (bread never chooses its own tan; a timer decides when it pops up).
